# Personalized Learning Platform

This platform supports the Personalized Learning System (PLS).  The platform is a microservice based architecture implemented primarily in Go, with several REST APIs designed to support the capabilities described in the design documentation for the PLS.

## Goals & Design Principles

The PLS aims to create a more effective and personalized learning experience by:

1. Supporting both academic knowledge acquisition and practical skill development
2. Representing learning as interconnected knowledge graphs that capture:
   - Core academic concepts and their relationships
   - Practical skills and competencies
   - Learning context and goals
   - Actions and progress

3. Enabling personalized learning paths by:
   - Tracking individual learner progress and goals
   - Adapting content and pacing to each learner
   - Providing relevant context for practical application
   - Supporting different learning styles and approaches

4. Facilitating institutional use through:
   - Curriculum mapping and alignment
   - Progress tracking and assessment
   - Learning analytics and insights
   - Integration with existing systems

The system is designed around representing both theoretical knowledge and practical skills in ways that support personalized learning journeys while meeting institutional needs for structure and assessment.
